6. System changes made by Setup

Setup requires administrator privileges. It removes the Microsoft Store version of Notepad installed for the current user and attempts to remove the corresponding provisioned package. It also writes Image File Execution Options (IFEO) registry configuration that redirects calls to notepad.exe to the replacement program you select.

On supported 64-bit Windows 11 systems, Setup also deploys a File Explorer context-menu component. To register that component, Setup may add the certificate used to sign the MSIX package to the local machine TrustedPeople certificate store. Uninstall attempts to remove the IFEO configuration, context-menu registration, related certificate, and installed files created by this software.
